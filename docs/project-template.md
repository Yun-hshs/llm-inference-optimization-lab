# Project Template

Each subproject should include the following sections.

## Goal

One sentence describing the technical problem.

## Background

Explain the model, kernel, system, or paper idea being reproduced.

## Implementation

- baseline
- optimized version
- correctness check
- benchmark

## Metrics

- latency
- throughput
- memory usage
- numerical error
- hardware and software environment

## Results

Add tables and charts after running experiments.

## Interview Talking Points

- What problem did this solve?
- What bottleneck did you identify?
- What optimization did you apply?
- How did you validate correctness?
- How would you improve it for production?
